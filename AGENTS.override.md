# Agent Continuity Entry Point

Read the existing `AGENTS.md` if present, then `docs/agent/PROJECT_KNOWLEDGE.md`, `docs/agent/INTEGRATIONS.md`, and `docs/agent/HANDOFF.md`.

Before final verification, update durable context for material commands, environment-variable **names**, connectors, data sources, constraints, and decisions discovered. After verification, update the handoff whenever work remains, including state, files, tests and exact failures, environment, approval, and one executable next action. If complete, clear stale steps and set `Status: Complete — no active handoff`.

Never record secrets, values, customer data, or private infrastructure. Work autonomously on routine reversible repository tasks. Verify connectors with a harmless read. Pause for production, destructive/data writes, credentials/permissions, auth/security, billing, public publishing, or access outside the task.
