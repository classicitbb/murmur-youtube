# Integrations and Connector Contract

- GitHub repository access is verified for source and draft-PR work.

- Add other services only after a harmless read verifies the target.
- Prefer authenticated MCP, then approved CLI/SDK, then controlled browser work.
- Store credentials only in approved secret systems.
- Production, data, auth/security, credential, messaging, billing, destructive, and access-expansion operations are approval gates unless explicitly authorized.
